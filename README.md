# 🏠 Facade Designer

App web pour designer la façade extérieure de votre maison en 3D.

## 🌐 Live Demo

**[Voir l'app en ligne](https://votre-username.github.io/Khedo-)**

## ✨ Fonctionnalités

- 🎨 **6 matériaux** : Brique, Pierre, Bois, Crépi, Béton, Carrelage
- 🏗️ **6 éléments** : Fenêtre, Porte, Garage, Balcon, Cheminée
- 💰 **Estimation de prix** en temps réel
- 📷 **Export image PNG**
- 🖱️ **3D interactif** (rotation, zoom)
- 📱 **Responsive** (PC, tablette, mobile)

## 🚀 Déploiement

### GitHub Pages (Gratuit)

1. Upload ces fichiers dans votre repo GitHub
2. Allez dans **Settings** → **Pages**
3. Source : **Deploy from a branch**
4. Branch : **main** / **root**
5. Sauvegarder → L'app sera en ligne en 2 minutes

## 🛠️ Technologies

- HTML5 / CSS3 / JavaScript
- Three.js (3D rendering)
- GitHub Pages (hosting)
